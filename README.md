# Inclisiverse Website Figma (Copy)

This is a code bundle for Inclisiverse Website Figma (Copy). The original project is available at https://www.figma.com/design/lx7Wwmk5SVY0OrR2ZZ8wi5/Inclisiverse-Website-Figma--Copy-.

## 🚀 Features

- **Multi-page Application**: Includes Home, About, Team, Timeline, Gallery, Join Us, and Contact Us pages.
- **Accessibility**: Features a dedicated Dyslexia mode toggle.
- **Gallery with Filtering**: Dynamic image gallery with category filtering.
- **Admin Panel**: For managing content and movie tickets.
- **Legal Pages**: Terms of Service, Privacy Policy, Cancellation Policy, and No Refund Policy.
- **Page Transitions**: Smooth animations using Framer Motion.
- **SEO Optimized**: Dynamic updates of meta tags and document titles per route.

## 🛠️ Tech Stack

- **Frontend Framework**: React 18
- **Build Tool**: Vite 6
- **Styling**: Tailwind CSS v4, Emotion
- **Animations**: Framer Motion
- **UI Components**: Radix UI primitives for accessible components
- **Other Utilities**:
  - `react-hook-form` for form handling
  - `recharts` for data visualization
  - `sonner` for toast notifications
  - `embla-carousel-react` for carousels
  - `date-fns` for date formatting

## Running the code

Run `npm i` to install the dependencies.

Run `npm run dev` to start the development server.
